# OpenFarmPlanner (local)

Working project for running [OpenFarmPlanner](https://openfarmplanner.org/en), the open-source
(AGPL-3.0) crop planning tool for market gardens and CSAs, locally on a PC (later perhaps a
Synology NAS). The aim is to plan crops, beds, timing and cultivation together with an LLM,
using the community crop library, and to add missing features (offered upstream where useful).

Moving to another PC: [docs/setup-new-machine.md](docs/setup-new-machine.md).

Agents and contributors: start with [AGENTS.md](AGENTS.md) and [HANDOFF.md](HANDOFF.md).

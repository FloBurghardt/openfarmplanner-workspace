Investigation and setup for running OpenFarmPlanner (AGPL-3.0, Django + React) locally on a PC,
later a Synology NAS, so crops, beds, timing and cultivation can be planned together with an
LLM, and missing features added. Reusable so far: the findings in
records/work/261117_idea_local_openfarmplanner/analysis.md on the app's API tokens (crops only
writable), the CC BY-SA crop library and how to reach it. Start with HANDOFF.md.

## Carry-over
May reuse: findings and decision records; any code, under AGPL-3.0.
Must not leave the project: the user's own farm and planning data.
